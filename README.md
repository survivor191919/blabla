# Индикаторы для TradingView

| Файл | Что это |
|------|---------|
| [`auction_flow_pro.pine`](auction_flow_pro.pine) | **Auction Flow Pro**: ордерфлоу, профиль объёма, VWAP и теория аукциона |
| [`rocket_or_bottom.pine`](rocket_or_bottom.pine) | «Ракета или Дно»: шуточный индикатор с мемными сигналами |

> ⚠️ Оба индикатора — инструменты анализа, а не финансовый совет. Результаты
> проверки на истории — в [`docs/VALIDATION.md`](docs/VALIDATION.md).

## Как установить

1. Откройте нужный `.pine`-файл и скопируйте код целиком.
2. В TradingView внизу откройте **Pine Editor**, выделите всё и вставьте код.
3. Нажмите **Add to chart** («Добавить на график»).
4. Если появилась ошибка компиляции, пришлите номер строки и текст ошибки.

## Auction Flow Pro (AFP)

### Что на графике

| Элемент | Что показывает |
|---------|----------------|
| **VWAP сессии** и полосы ±1σ/±2σ | Справедливая цена дня и края распределения |
| **Developing POC** (оранжевая) и **VAH/VAL** (фиолетовые) | Где сегодня торгуется основной объём |
| **POC/VAH/VAL прошлой сессии** (серые) | Вчерашняя ценность, главные аукционные уровни |
| **«Голые» POC** (жёлтый пунктир) | POC прошлых сессий, до которых цена ещё не доходила. Работают как магниты |
| **Гистограмма профиля** справа | Объём по ценам за сессию. Цвет строки — знак дельты |
| **◆ маркеры** | Поглощение: большой объём упёрся в пассивную сторону |
| **Метки ▲ LONG / ▼ SHORT** | Сигналы. Наведите курсор, чтобы увидеть вход, стоп, цели и факторы |
| **Панель** | Состояние аукциона, дельта, CVD, RVOL, уровни и статистика сигналов |

### Сигналы (сетапы)

1. **Поглощение.** Агрессивные продажи (покупки) у уровня не двигают цену.
   Сигнал приходит после подтверждения: закрытия за экстремумом бара.
2. **Ложный пробой ценности.** Цена вышла за VAH/VAL прошлой сессии и вернулась.
   Аукцион в ту сторону провалился.
3. **Правило 80%.** Сессия открылась вне ценности и вернулась в неё с принятием.
   Цель — противоположная граница Value Area.
4. **Отбой от ±2σ.** Разворот на краю распределения VWAP.
5. **Ретест после принятия.** Рынок принял цены за границей ценности, откат к
   уровню выкупается (продаётся).

У каждого сигнала есть грейд (**B / A / A+**): сколько из 5 подтверждений
выполнено. Подтверждения:

- уровень;
- дельта;
- поглощение;
- проба без инициативы (слабый объём);
- контекст аукциона.

Стоп ставится за структуру. Цели — ближайшие аукционные уровни не ближе 1R.

### Встроенная статистика

Трекер ведёт каждый сигнал: половина позиции закрывается на T1, стоп переносится
в безубыток, остаток выходит на T2. Строка «Статистика» на панели показывает
результат на загруженной истории. Если навести на неё курсор, видна разбивка по
сетапам. Так можно проверить индикатор на своём инструменте и таймфрейме.

### Что важно знать

- **Биржевого стакана (DOM) в Pine Script нет.** Дельта восстанавливается по
  свечам меньшего таймфрейма, от 1 минуты. Панель показывает, какая доля истории
  посчитана по интрабарам. Остальное считается грубой оценкой по свече.
- Лучше всего подходят внутридневные графики **от 2 до 60 минут**.
- На истории TradingView (15m, 7 инструментов) у сигналов **не найдено устойчивого
  преимущества**, результат около нуля. Подробности в
  [`docs/VALIDATION.md`](docs/VALIDATION.md).
- Сигналы появляются только **после закрытия бара** и не перерисовываются.

### Алерты

- **«AFP: сигнал LONG / SHORT / любой сигнал»** — простые условия.
- **«Any alert() function call»** — сообщение с сетапом, грейдом, входом, стопом и
  целями.
