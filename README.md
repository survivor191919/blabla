# Ракета или Дно 🚀💀

Шуточный индикатор для TradingView на Pine Script v6. Рисует на графике сигналы с мемными подписями и показывает «настроение рынка».

> ⚠️ Это не финансовый совет. Индикатор сделан для фана. Не продавай почку по его сигналам.

## Что он показывает

| Метка | Что значит |
|---|---|
| 🚀 **ПОКУПАЙ** | Быстрая EMA (9) пересекла медленную (21) снизу вверх, RSI не в перекупленности, цена выше EMA 200 |
| 💀 **ПРОДАВАЙ** | Быстрая EMA пересекла медленную сверху вниз, RSI не в перепроданности, цена ниже EMA 200 |
| 🔥 | RSI зашёл в перекупленность (выше 70) |
| 🧊 | RSI ушёл в перепроданность (ниже 30) |
| 🐋 | Кит: объём в 3 раза выше среднего и свеча больше ATR |

В правом верхнем углу есть панель **«Настроение рынка»**: индекс от 0 до 100, который считается из RSI, положения цены относительно EMA 200 и взаимного положения быстрой и медленной EMA. Уровни: 😱 ПАНИКА, 😰 Страшновато, 😐 Непонятно, 😎 Уверенность, 🤑 ЖАДНОСТЬ.

## Как установить

1. Открой любой график на [tradingview.com](https://www.tradingview.com).
2. Внизу открой вкладку **Pine Editor**.
3. Вставь содержимое файла [`rocket_or_bottom.pine`](rocket_or_bottom.pine).
4. Нажми **Add to chart** («Добавить на график»).

## Алерты

В меню алертов появятся три условия: 🚀 Ракета, 💀 Дно, 🐋 Кит. Их можно повесить на любой тикер, и TradingView будет присылать уведомления.

## Настройки

Все периоды (EMA, RSI), уровни перекупленности и перепроданности, множитель объёма для кита и фильтр по EMA 200 меняются в настройках индикатора. Мем-метки, линии EMA и панель настроения можно отключить.
