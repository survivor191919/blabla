# Аудит auction_flow_pro.pine под Pine Script v6 (шаг 9)

Компилятор Pine есть только у TradingView, поэтому код проверен вручную по
списку известных ловушек v6 и линтером `tools/pine_lint.py`.

| # | Проверка | Результат |
|---|----------|-----------|
| 1 | Строки-продолжения не имеют отступа, кратного 4 | ✔ линтер |
| 2 | Нет зарезервированных слов в именах (`method`, `type` и т. д.) | ✔ найдено и исправлено `method` |
| 3 | Нет затенения глобальных переменных локальными | ✔ линтер |
| 4 | Каждая переприсваиваемая переменная объявлена | ✔ линтер |
| 5 | `plot`, `plotshape`, `fill`, `bgcolor`, `barcolor`, `alertcondition` только в глобальной области | ✔ |
| 6 | `ta.*` не вызываются внутри условий и локальных блоков (ленивые `and`/`or` в v6) | ✔ все `ta.*` на верхнем уровне |
| 7 | `bool` нигде не получает `na` | ✔ |
| 8 | Циклы `for i = 0 to n - 1` защищены от `n = 0` (иначе Pine идёт вниз) | ✔ 4 цикла проверены: `nIntra` под `if hasIntra`, `nSeg`, `cnt`, `nRows` ≥ 1 |
| 9 | Деление целых не используется как целочисленное (в v6 результат дробный) | ✔ индексы через `math.floor` / `math.ceil` |
| 10 | Коллекции (`map`, `array`) меняются только на закрытом баре | ✔ `barstate.isconfirmed` |
| 11 | Сигналы без перерисовки | ✔ только на закрытом баре; ATR якоря через `[1]` + `lookahead_on` |
| 12 | Лимиты объектов: линии ≤ 500 (сделки ≤ 400, «голые» POC ≤ 20), боксы ≤ 120, метки ≤ 500 | ✔ |
| 13 | Число графиков < 64 | ✔ около 30 |
| 14 | Отрицательные значения в `case` у `switch` | ✔ заменено на тернарный оператор |
| 15 | `request.security_lower_tf` не падает при недопустимом ТФ | ✔ `ignore_invalid_timeframe = true` |

Если TradingView всё же покажет ошибку компиляции, нужны номер строки и текст
ошибки.
