# План проекта: Auction Flow Pro (AFP)

Индикатор для TradingView (Pine Script v6), который строит сигналы на основе:
**ордерфлоу** (дельта объёма, CVD, поглощение), **профиля объёма / Market Profile**
(POC, Value Area, «голые» POC), **VWAP с σ-полосами** и **теории аукциона**
(баланс/дисбаланс, принятие/отвержение цены, ложные пробои ценности, правило 80%).

## Честные ограничения (важно понимать заранее)

1. **Биржевой стакан (DOM, Level 2) в Pine Script недоступен.** Ни один индикатор
   TradingView не видит реальные лимитные заявки. Поэтому «стакан» заменяется тем,
   что реально можно посчитать: агрессивной дельтой, поглощением объёма и
   профилем объёма по ценам.
2. **Настоящий тиковый ордерфлоу (bid/ask по каждой сделке) тоже недоступен.**
   Дельта считается по внутрибарным данным меньшего таймфрейма
   (`request.security_lower_tf`): каждая минутная (или секундная) свеча относится к
   покупкам или продажам. Это стандартная и достаточно точная аппроксимация. Если
   интрабаров нет, дельта оценивается по положению закрытия внутри свечи.
3. **Ни один индикатор не гарантирует прибыль.** Поэтому в индикатор встроена
   честная статистика: каждый сигнал отслеживается до стопа или цели, а на
   панели показывается реальный процент отработки на загруженной истории.
4. **Скомпилировать Pine здесь нельзя**, компилятор есть только у TradingView.
   Поэтому код пишется консервативно, с отдельным аудитом под Pine v6, а логика
   дублируется моделью на Python и проверяется на реальных данных.

## Шаги (выполняются строго по очереди)

| # | Шаг | Что получается на выходе | Критерий готовности |
|---|-----|--------------------------|---------------------|
| 1 | **План и спецификация** | `docs/PLAN.md`, `docs/SPEC.md` | Все формулы, сетапы и правила сигналов описаны однозначно |
| 2 | **Каркас + VWAP** | Настройки, якорь сессии (день/неделя/месяц), якорный VWAP с полосами ±1σ/±2σ/±3σ | VWAP сбрасывается по сессии, полосы считаются по взвешенной дисперсии |
| 3 | **Движок ордерфлоу** | Дельта из интрабаров (правило тика) с запасным методом, CVD сессии и непрерывный, RVOL по времени суток | Работает на любом ТФ, покрытие интрабарами видно на панели |
| 4 | **Профиль объёма** | Developing POC/VAH/VAL, уровни прошлой сессии, «голые» POC, гистограмма профиля с дельтой по строкам | Value Area 70% считается классическим расширением от POC |
| 5 | **Состояние аукциона** | Тип открытия, баланс/дисбаланс, принятие за пределами ценности, миграция ценности | Состояние однозначно определяется на каждом баре |
| 6 | **Сетапы и сигналы** | 5 сетапов, система баллов (грейды B / A / A+), стоп и цели по аукционным уровням | Сигналы только на закрытом баре, без перерисовки |
| 7 | **Визуал, панель, алерты, статистика** | Метки с подсказками, линии сделки, панель состояния, алерты, трекер результатов сигналов | Всё отключается в настройках, есть алерты с данными сделки |
| 8 | **Проверка на реальных данных** | Python-модель той же логики (`research/`), прогон на истории TradingView, калибровка порогов | Отчёт со статистикой в `docs/VALIDATION.md` |
| 9 | **Финальный аудит и документация** | Проверка кода по списку ловушек Pine v6, `README.md` с инструкцией | Чек-лист аудита пройден, инструкция по установке и чтению сигналов |

Каждый шаг оформляется отдельным коммитом.
