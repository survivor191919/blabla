# Спецификация Auction Flow Pro

Все расчёты делаются на закрытии бара, кроме отрисовки текущего состояния.
Обозначения: `ATR` — ATR(14) графика, `tol` — допуск касания уровня
(по умолчанию `0.25 × ATR`), `tick` — `syminfo.mintick`.

## 1. Сессия (якорь)

Якорь задаёт период, для которого строятся VWAP, профиль и CVD.

| Настройка | Якорь |
|-----------|-------|
| Авто на внутридневном графике | День (`D`) |
| Авто на дневном графике | Месяц (`M`) |
| Авто на недельном и старше | Год (`12M`) |
| Вручную | День / Неделя / Месяц |

Новая сессия начинается, когда `timeframe.change(якорь)` возвращает `true`.

## 2. Якорный VWAP и σ-полосы

Для бара с ценой `p = hlc3` и объёмом `v` за сессию накапливаются
`ΣPV = Σ p·v`, `ΣV = Σ v`, `ΣP²V = Σ p²·v`.

- `VWAP = ΣPV / ΣV`
- `σ = sqrt(max(ΣP²V / ΣV − VWAP², 0))` — объёмно-взвешенное стандартное отклонение
- Полосы: `VWAP ± k·σ`, где `k = 1, 2, 3`
- Положение цены в σ: `(close − VWAP) / σ`

## 3. Ордерфлоу

### 3.1 Дельта бара

**Метод «Интрабары»** использует свечи меньшего таймфрейма, полученные через
`request.security_lower_tf`. Каждый интрабар целиком относится к покупкам или
продажам по правилу тика:

- `close > open` → покупка; `close < open` → продажа
- при `close = open` сравнение с закрытием предыдущего интрабара, а если цена
  не изменилась, берётся направление предыдущего интрабара

Автовыбор интрабарного ТФ: секундный график → `1S`; от 2 минут до 1 часа → `1`;
до 4 часов → `5`; дневной → `60`; старше → `240`. На минутном графике минутные
интрабары ничего не добавляют, поэтому используется запасной метод (при наличии
секундных данных можно вручную поставить `1S`).

**Запасной метод «Оценка по свече»**, если интрабаров нет:
`buy = v × (close − low) / (high − low)`, `sell = v − buy`.

Итоговые величины:

- `delta = buy − sell`, `delta% = delta / v` (от −1 до +1)
- `CVD сессии` — сумма дельты с начала сессии
- `CVD непрерывный` — сумма дельты по всей истории (для дивергенций)
- Покрытие: доля баров, у которых дельта посчитана по интрабарам

### 3.2 RVOL по времени суток

Для номера бара внутри сессии `n` хранится экспоненциальное среднее объёма за
последние `N` сессий (по умолчанию 20) на этом же номере бара.
`RVOL = v / среднее(n)`. Пока у номера бара меньше трёх наблюдений,
используется `SMA(volume, 20)`. Это убирает ложные «всплески» на открытии рынка,
где объём высокий каждый день.

### 3.3 Поглощение (absorption)

Бар считается поглощением, если выполнено одно из условий.

- **Дельта против цены** (только при интрабарной дельте): `RVOL ≥ 1.5`,
  `delta% ≤ −0.20`, но закрытие в верхней половине бара (`CLV ≥ 0.5`). Продавцы
  били по рынку, а цена не пошла вниз, значит пассивный покупатель поглотил
  продажи. Бычье поглощение. Медвежье — зеркально.
- **Усилие без результата**: `RVOL ≥ 2.0` и диапазон бара `≤ 0.7 × ATR`.
  Направление определяется положением бара: у поддержки или на локальном
  минимуме за 20 баров — бычье, у сопротивления или на максимуме — медвежье.

### 3.4 Дивергенция CVD

Медвежья: `high` обновил максимум за 20 баров, а непрерывный CVD — нет.
Бычья — зеркально. Сигнал считается актуальным 5 баров.

## 4. Профиль объёма

- **Размер строки** фиксируется на старте сессии: `ATR(14) якорного ТФ за прошлый
  период / строк на ATR` (по умолчанию 40), округление до `tick`.
- **Распределение объёма**: объём каждого интрабара (или бара при запасном
  методе) делится поровну между строками его диапазона `low…high`. Отдельно
  копится дельта по строкам.
- **POC** — строка с максимальным объёмом. Хранится инкрементально.
- **Value Area (70%)** — классическое расширение от POC: на каждом шаге
  добавляется соседняя строка сверху или снизу с большим объёмом, пока не набрано
  70% объёма сессии. `VAH` — верх верхней строки, `VAL` — низ нижней.
- **Developing** POC/VAH/VAL пересчитываются на каждом закрытом баре.
- **Уровни прошлой сессии**: `pPOC`, `pVAH`, `pVAL`, `pHigh`, `pLow`
  фиксируются в момент смены сессии.
- **«Голые» POC**: POC прошлых сессий, до которых цена ещё не дошла. Хранятся
  последние 5. Уровень удаляется при первом касании.
- **Гистограмма** текущей сессии рисуется справа от последнего бара. Цвет
  строки задаётся знаком дельты, яркость — попаданием в Value Area.

## 5. Состояние аукциона

- **Тип открытия**: открытие сессии выше `pVAH`, ниже `pVAL` или внутри ценности.
- **Принятие**: `N` закрытий подряд за пределами прошлой ценности, где
  `N = max(2, round(30 мин / ТФ))`. Принятие снимается, когда `N` закрытий подряд
  оказываются внутри ценности или за противоположной границей.
- **Состояние** (одно на каждый бар):

| Код | Состояние | Условие |
|-----|-----------|---------|
| +2 | Дисбаланс ↑ | принятие выше `pVAH` |
| +1 | Тест вверх | закрытие выше `pVAH` без принятия |
| 0 | Баланс | закрытие внутри `pVAL…pVAH` |
| −1 | Тест вниз | закрытие ниже `pVAL` без принятия |
| −2 | Дисбаланс ↓ | принятие ниже `pVAL` |

- **Миграция ценности**: developing POC выше `pVAH` означает, что ценность
  смещается вверх, ниже `pVAL` — вниз, иначе прошлая и текущая ценность
  перекрываются.

## 6. Сетапы

Ключевые уровни: `pVAH`, `pVAL`, `pPOC`, `pHigh`, `pLow`, «голые» POC, `VWAP`,
`±1σ`, `±2σ`, developing POC. Все условия описаны для лонга, шорт зеркален.

| # | Сетап | Условие лонга | Стоп |
|---|-------|---------------|------|
| 1 | **Поглощение** | Бычье поглощение (п. 3.3) у ключевого уровня или на 20-барном минимуме. При включённом подтверждении сигнал приходит, когда в течение 3 баров цена закроется выше максимума бара поглощения. Отмена: закрытие ниже его минимума | Минимум бара поглощения − буфер |
| 2 | **Ложный пробой ценности** | Для уровня `L ∈ {pVAL, pLow}`: `low < L` и `close > L` с `CLV ≥ 0.5` (прокол), либо прошлый бар закрылся ниже `L`, а текущий бычий бар закрылся выше `L` | Минимум двух баров − буфер |
| 3 | **Правило 80%** | Сессия открылась ниже `pVAL`, затем `N` закрытий подряд внутри ценности. Один раз за сессию | `min(минимум N баров, pVAL)` − буфер |
| 4 | **Отбой от −2σ** | `low ≤ VWAP − 2σ`, `close > VWAP − 2σ`, бар бычий (`close > open` или `CLV ≥ 0.6`) | Минимум бара − буфер |
| 5 | **Принятие и ретест** | Состояние +2 (или +1 для ретеста VWAP в дисбалансе ↑). Откат: `low ≤ L + tol`, `close > L`, бычий бар, где `L ∈ {pVAH, VWAP, dPOC}` | `min(low, L)` − буфер |

- Буфер стопа: `0.1 × ATR`.
- Минимальный риск: `0.3 × ATR`. Если стоп ближе, он отодвигается.
- Максимальный риск: `2.5 × ATR`. Если стоп дальше, сигнал отбрасывается.

## 7. Баллы и грейды (версия v2 после проверки, см. docs/VALIDATION.md)

| Фактор | Балл |
|--------|------|
| Уровень: у экстремума реакции есть ключевой уровень | +1 |
| Дельта подтверждает: `delta%` бара сигнала ≥ +0.10 | +1 |
| Поглощение в сторону сделки за последние 3 бара | +1 |
| Проба без инициативы: `RVOL < 1.3` (у сетапа «Поглощение» засчитывается всегда) | +1 |
| Контекст: для разворотных сетапов аукцион не в дисбалансе против сделки; для ретеста CVD сессии в сторону сделки | +1 |

Дивергенция CVD показывается в подсказке, но не голосует. Ложный пробой
максимума и минимума прошлой сессии выключен по умолчанию.

Грейды (максимум 5 баллов): **B** — 3, **A** — 4, **A+** — 5. По умолчанию грейд A.

Защита от шума:

- после сигнала 3 бара пауза;
- на историческом и реальном баре сигнал появляется только после закрытия бара
  (`barstate.isconfirmed`).

## 8. Цели

Кандидаты: все ключевые уровни, developing VAH/VAL, максимум и минимум текущей
сессии.

- **T1** — ближайший уровень в сторону сделки на расстоянии не меньше `1R`.
- **T2** — ближайший уровень на расстоянии не меньше `max(2R, T1 + 0.5R)`.
- Если подходящего уровня нет, берутся `T1 = 1.5R` и `T2 = 3R`.

## 9. Трекер результатов (встроенная статистика)

Каждый сигнал сопровождается до выхода.

1. Вход по закрытию бара сигнала.
2. До T1: если достигнут стоп, результат −1R. Если в одном баре достигнуты и
   стоп, и T1, засчитывается стоп (консервативно).
3. По достижении T1 фиксируется половина позиции, стоп переносится в безубыток.
4. После T1: выход в безубыток или по T2.
5. Если через `maxHold` баров (по умолчанию 48) сделка не закрыта, остаток
   выходит по закрытию.

Статистика на панели: число сделок, доля дошедших до T1 и до T2, средний
результат в R.
